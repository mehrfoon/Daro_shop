# داروشاپ | Daro Shop

قالب فارسی راست‌چین فروشگاه سلامت و داروخانه، همراه با پیش‌نمایش استاتیک.

## پیش‌نمایش آنلاین
پس از فعال‌سازی GitHub Pages:
https://mehrfoon.github.io/Daro_shop/

## انتشار پیش‌نمایش
در مخزن GitHub وارد Settings → Pages شوید. گزینه **Deploy from a branch**، شاخه **main** و پوشه **/(root)** را انتخاب و Save کنید. فایل `index.html` صفحه نمایشی است و به PHP یا پایگاه داده نیاز ندارد.

## نصب قالب وردپرس
1. پوشه `wordpress-theme/daro-shop` را به ZIP تبدیل کنید.
2. در پیشخوان وردپرس: نمایش ← پوسته‌ها ← افزودن پوسته تازه ← بارگذاری پوسته.
3. افزونه WooCommerce را نصب و فعال کنید و محصولات، دسته‌ها، صفحات و روش‌های ارسال را تنظیم کنید.
4. برای پیامک، درگاه پرداخت، رهگیری سفارش و سرویس ارسال، افزونه و ارائه‌دهنده معتبر و سازگار با کشور/هاست خود را جداگانه پیکربندی کنید.

## امکانات قابل راه‌اندازی با WooCommerce و افزونه‌ها
سبد خرید، سفارش‌ها، کوپن و تخفیف زمان‌دار، محصولات مرتبط، امتیاز و دیدگاه، دسته‌بندی و برچسب، محدودیت حداقل/حداکثر خرید، روش‌های ارسال و وضعیت سفارش. پیامک و درگاه پرداخت به سرویس و تنظیمات جداگانه نیاز دارند.

## نکته مهم
صفحه GitHub Pages صرفاً پیش‌نمایش است؛ سفارش و پرداخت واقعی ندارد. برای اجرای وردپرس به هاست دارای PHP و MySQL نیاز است. عرضه دارو و اقلام مشمول ضوابط، فقط با مجوزهای قانونی و رعایت مقررات مربوط امکان‌پذیر است. اطلاعات و قیمت‌های پیش‌نمایش نمونه هستند.
